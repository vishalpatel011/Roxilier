# Coding Challenge Project

## 🚀 Overview
A MERN stack application that fetches and visualizes data using charts.

## 🔧 Installation & Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/vishalpatel011/Roxilier.git
   cd Roxilier

2. Install Dependencies
    npm install

3. Run the project
    npm start


## 🛠 Tech Stack
React
Node.js
Express
MongoDB
Chart.js
